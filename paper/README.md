# `paper/` — the manuscript, and which script makes which table

`manuscript.pdf` is the paper as submitted to Mathematical Programming
Computation. **The LaTeX sources are not part of this package**; what is here is
everything the manuscript `\input`s or shows, together with the scripts that
regenerate it.

## Table and figure map

| in the paper | file here | regenerated by |
|---|---|---|
| **Table 1** — feasible rounded points above the cutoff; position in the band | *(body pasted into the .tex, not `\input`)* | `cd ../prototype && python agg_band.py --latex`, plus `--band-lam 0.25` and `--band-lam 0.75` for the two extra levels |
| **Figure 1** — where the lost improving points sit | `fig5_band.pdf` *(generated, git-ignored)* | `python figs_v2.py`, from `band_positions.csv` |
| **Table 2** — E1, the twelve pre-declared paired comparisons, Holm | `tab_fact_paired.tex` | `cd ../campaign_scip && python mk_tabs_fact.py` |
| **Table 3** — E3, target experiment, outcome | `tab_target_outcome.tex` | `cd ../campaign_gurobi && python mk_tab_target.py`, then copy here |
| **Table 4** — E1 per arm (176 instances) | `tab_fact_e1.tex` | `cd ../campaign_scip && python mk_tabs_fact.py` |
| **Table 5** — E2 per arm (248 instances) | `tab_fact_e2.tex` | idem |
| **Table 6** — found / not found, paired per run | `tab_fact_found.tex` | idem |
| **Table 7** — E3, paired comparisons on the outcome | `tab_target_paired.tex` | `cd ../campaign_gurobi && python mk_tab_target.py`, then copy here |

Two conventions differ between the two families of tables, and it matters when
recompiling:

* the four `tab_fact_*.tex` contain **only** the
  `\begin{tabular}…\end{tabular}` body. The `table` environment, the caption and
  the label are written by hand in the manuscript, `booktabs` is already loaded
  in its preamble, and the body size (`\footnotesize` and the like) is decided by
  the `.tex`. The arm names are the macros `\armnone`, `\armchk`, `\armfgl`,
  `\armfb`, `\armfbn` defined in the preamble.
* the two `tab_target_*.tex` carry **their own** `table` environment, caption and
  label, and are simply `\input`.

Every generated `.tex` opens with two `%%` provenance lines giving the exact
command and the **absolute path** of the input file. That second line is
machine-dependent by construction: when comparing a regenerated table against the
copy shipped here, compare from line 3 on.

## `figs_v2.py`

```bash
python figs_v2.py
```

reads `band_positions.csv` (produced by
`cd ../prototype && python agg_band.py --hist --dump band_positions.csv`, default
options) and writes **`fig5_band.pdf`**, the only figure of the paper. It needs
`matplotlib`; the figure itself is git-ignored because it is regenerable.

The script also contains a `fig_profile()` that would draw a performance profile
of E1 from `e1_profile.csv`. **That figure is no longer in the paper**, the CSV
comes from a superseded campaign and is not shipped, and the function prints
`manca e1_profile.csv: salto fig6` and returns. Ignore it.

## Testbed, in one line

MIPLIB 2017 instances with at least 80 % binary variables: 463 probed, **424
analysed, 25,440 runs**, strata E1 = 176 and E2 = 248. The exclusions are
declared, not silent — 37 instances whose first LP is not solved within the 600 s
of the probe, 2 with an incomplete arm × seed grid because of a numerical error
in SCIP — and `../campaign_scip/agg_fact.py` prints all 39 by name, for the
supplementary material.
