# `paper/` — the manuscript, and which script makes which table

`manuscript.pdf` is the paper as submitted to Mathematical Programming
Computation. **The LaTeX sources are not part of this package**; what is here is
everything the manuscript `\input`s or shows, together with the scripts that
regenerate it.

Two conventions differ between the two families of tables, and it matters when
recompiling:

* the four `tab_fact_*.tex` contain **only** the
  `\begin{tabular}…\end{tabular}` body. The `table` environment, the caption and
  the label are written by hand in the manuscript, `booktabs` is already loaded
  in its preamble, and the body size (`\footnotesize` and the like) is decided by
  the `.tex`. The arm names are the macros `\armnone`, `\armchk`, `\armfgl`,
  `\armfb`, `\armfbn` defined in the preamble.
* the two `tab_target_*.tex` carry **their own** `table` environment, caption and
  label, and are simply `\input`.

Every generated `.tex` opens with two `%%` provenance lines giving the exact
command and the **absolute path** of the input file. That second line is
machine-dependent by construction: when comparing a regenerated table against the
copy shipped here, compare from line 3 on.

## `figs_v2.py`

```bash
python figs_v2.py
```

reads `band_positions_3seeds.csv` (produced by
`cd ../prototype && python agg_band_seeds.py --latex --dump ../paper/band_positions_3seeds.csv`:
one row per lost improving rounded point, three seeds) and writes
**`fig5_band.pdf`**, Figure 2. If that file is missing it falls back on
`band_positions.csv` (seed 0 only, `agg_band.py --hist --dump`), which is the
figure of the earlier versions of the paper and is kept for that reason only.

```bash
python fig_pingpong.py [instance] [rounds]      # default: scpnrh3 150
```

reads the per-round trace `<instance>__cutoff_lam0.5_s0.csv` (and its `.json`)
in `../prototype/grid/` and writes **`fig7_pingpong.pdf`**, Figure 1. Both need
`matplotlib`; both figures are git-ignored because they are regenerable.

## Testbed, in one line

MIPLIB 2017 instances with at least 80 % binary variables: 463 probed, **424
analysed, 25,440 runs**, strata E1 = 176 and E2 = 248. The exclusions are
declared, not silent — 37 instances whose first LP is not solved within the 600 s
of the probe, 2 with an incomplete arm × seed grid because of a numerical error
in SCIP — and `../campaign_scip/agg_fact.py` prints all 39 by name, for the
supplementary material.
